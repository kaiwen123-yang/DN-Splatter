## 运行和接续

服务器项目为 `/root/autodl-tmp/DN-Splatter`，运行目录为其下 `.local/runs/interactive-world-20261128-v1`。从项目根目录执行以下命令。

```bash
bash scripts/launch_interactive_world.sh status
bash scripts/launch_interactive_world.sh attach
```

总调度使用 `dn-interactive` socket 和 `interactive-world` 会话。A 线使用 `iw-a` socket 和 `iw-a-coordinator` 会话。训练每 10k 保存恢复点，每 30k 评大厅全验证集。单组异常与恢复命令在各自的 `state` 和 `logs` 中，整体准入记录在 `state/queue.json`、`state/admission.json` 和 `state/coordinator-events.jsonl`。按北京时间每天及 checkpoint/重要产物变化生成日志。服务器保存模型、全量视频、轨迹、哈希清单；GitHub 收录可核对的小报告和预览。[资源与归档身份](inventory.json) · [每日日志](../../../DAILY_RESEARCH_LOG.md)
