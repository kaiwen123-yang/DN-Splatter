## 3. A 阶段：冻结 B2，先改网格

**A1 建局部表面。** 用 B2 210k 渲染全部训练相机，读取预测光轴 Z、累计透明度、法线。校准原生深度、光轴、单位和像素中心沿用 B2；模型深度与原生深度在各自相机中处理。按首张主训练图为起点，每 2 s 分不重叠的局部子图，若相邻训练相机转角超过 90° 则断开，边界两侧不互相积分。每帧只归属一个子图。共用世界原点与 1 cm 体素格，局部 TSDF 截断 4 cm，稀疏分块提取局部候选曲面。模型分支用预测 Z、有限法线、α≥0.5；原生分支用有限有效实测 Z。保留每块来源帧、法线、空间位置和可见区域。最终模型网格中的几何位置只来自模型或同模型旧网格，传感器仅验证支持；传感器分支的几何位置只来自实测。

**A2 判定不同机位是否看到了同一表面。** 在原生深度网格投影模型候选点，取首层有效观测。按 0.3–1、1–2、2–4、4–6 m 四档，使用互相可见、远离深度断边的训练帧对估计两帧有符号 Z 残差的 MAD。支持容差用 `min(0.20 m, max(0.05 m, 0.03·Z, 2.5·1.4826·MAD))`。一档少于 1,000 个互相有效采样或 10 对不同训练帧时，回退既有 `max(0.05 m,0.03·Z)`，记录数量和回退。此容差只用于建图。正式评价始终使用 B2 定义。

每个候选在一个子图至多贡献一票，保留观测中离断边更远且一致残差更小的一帧。跨子图的两票要同时满足光心相距至少 0.10 m、从候选点看向光心的视线夹角至少 3°。近重复机位合并；源子图不能为自己的候选提供独立认证。区分四种证据：

| 观测 | 处理 |
| --- | --- |
| 候选 Z 与可靠实测首面相符 | 记表面支持，记录视角与残差 |
| 候选在可靠首面前方、超过容差 | 记候选可能占据自由空间；仅内点可投此票 |
| 候选在已观测前景之后 | 标为被遮挡，弃权 |
| 越界、没有有效 Z、离原生深度断边或无效边界 ≤2 px | 标为未知，不投自由空间票；保留局部边缘候选供其他视角验证 |

原生深度的断边按相邻有效 Z 差超过该处基础容差识别；孔洞不双线性补深度。新层至少需两个独立外部机位组支持，且支持多于可信冲突。模型自身的异视角一致性单独记录；只有模型证据的区域标低置信，不据此删除遮挡边缘或填补无实测支持的大洞。

**A3 合入全局并保留细结构。** 对模型分支，以该模型的既有支持 Poisson 为底图。新、旧两层明显冲突时，只有旧层被至少两个独立外部机位组确认占据自由空间，且新层满足 A2 支持，才局部替换。旧层已有空洞时允许有独立支持的新面补入。无法取得足够证据时保留旧面，记录回退区域。原生分支从传感器局部面开始，按同样的跨组支持融合，覆盖未知处保持显式空洞。两种来源分别输出，不以传感器网格参加模型网格竞选。

在共享稀疏格上给同一局部曲面选一个持有子图，依次比较独立支持数、支持残差和子图 ID。只合并同层且法线夹角不超过 30° 的面片；前后层、细杆两侧按有向法线分别保留。替换边界进行裁接、共享边去重，保留原三角形的可见性，检查顶点、边中点和面中心；不跨明确断边补三角形。保存支持/冲突/遮挡/弃权、成功替换/补入/回退面积、重复面与退化面数量、三角面数和哈希。若新导出出现技术错误作最小实现修复；新方案自身导致孔洞或碎面则保留结果供评价。

**A4 用相同证据核验。** 对训练帧 00000、00330、01420 重跑同相机回投；对既有四个缺面位置报告局部与全局变号、命中和冲突。它们用于解释机制。完整 184 val 与 B2 支持 Poisson、模型 TSDF、原生 TSDF 配对，计算原来正确而现在丢失、原来错误/缺失而现在正确的像素数，按固定物体和深度段出图。A 的阈值和候选随后冻结，统一开发 test 留在最后。

## 4. B 阶段：确定哪些改动值得训练

**位姿。** 对 1304、1305 作联合重定位。用于求解的 3D 点必须有坏段外固定主训练地图支持，两个可疑帧之间的互相匹配只用于关联。保留 B2 全局米制、内参和区间外锚点。用真实匹配做 PnP/RANSAC 和局部训练位姿优化；拟合至少 20 个 PnP 内点、两个外部机位组，中位重投影误差 ≤2.5 px。另按外部来源轨迹/图像分出不参与拟合的**训练**对应。对新旧解在相同留作核验的训练匹配和共同深度支持位置上比较：中位重投影误差下降、两端双向 ≤10 cm 一致率改善，且共同有效重叠没有因投出画面而虚增。正深度、两端位移/旋转、有效像素总数均要报告。缺验证对应或证据相冲突就保留原解并标记。1514 单独检查实拍拖影和两个邻接边。仅当多处静态、不同朝向平面与真实 RGB 对应共同支持同一子图刚体偏差时，才对该局部加固定边界的校正；退化方向维持原估计。留出在新训练地图上定位，失败保留原估计和标志，禁止插值、手写翻转或删除失败帧。

**深度监督。** 在拟用于训练的位姿上重新计算观测可靠性，独立组数排除源帧、源子图和近重复机位。对每个真实有效深度像素，令 S 是独立支持组数、C 是可信自由空间冲突组数。预设权重 `w=(1+S)/(1+S+C)`，遮挡、未知和断边弃权，无外部证据时 w=1。在 B2 的 EdgeAwareLogL1 每个方向原有有效元素上使用加权均值，各方向有效分母为对应权重和；全 1 须与 B2 损失及梯度在浮点精度内一致，空项沿用零贡献并记数。用额外留出的训练机位组交叉核验低权重像素是否确有更大的独立残差；只在跨组验证方向成立且有非恒等权重时启用，记录每距离档覆盖和总有效权重。模型保留全部 RGB 和 B2 法线主损失；无实测处保持未知。前方透射率或层间分散可以记录；B3 训练不引入需要新光栅器的损失，从一个期望深度和总 α 推不出每一层的贡献。

**纹理。** 从未压缩训练图中按泡沫凸纹、桌沿纹理、细网格选有重复观察的区域，先保存固定区域、源帧、基线和清晰度；开发测试局部只用于交付。用受支持的同一表面和真实可见性重投影，计算相同物体边缘在两视角的错位、局部梯度与 B2 预测的高频残差。预注册实现默认：32×32 像素块，有效重叠 ≥50%，同一细节在至少两个独立清晰训练机位对齐到中位 1 px 内，且两视角的高通 RGB 误差都超过各自有效训练块的第 90 百分位。高通取 RGB 减去 σ=1 px 的高斯低通；按块平均绝对值排序。清晰机位按同一块在不同机位的实拍梯度能量不低于其中位数判断。满足时，将残差归给真实参与该像素成像、可追溯的可见高斯；若现有渲染接口不足以可靠归因，记录并关闭额外细分。正式增长期每次只在原有可分裂尺寸和可见性条件下增加父点，数量至多为该次原定分裂父点数的 10%（向下取整），同一父点只处理一次，按跨视角残差再按稳定索引排序。只在对齐清楚且证据持续的区域启用。模糊或反光未解决的区域保持原主 RGB 监督，报告实际覆盖。

**训练决定。** 记录 `accepted_pose_changes`、`depth_weights_enabled`、`texture_split_enabled` 及各自分母。至少一项实质改变时继续 C；局部失败不阻断其他已证实的修复。没有可用的新几何或优化信号时，继续最终评价、视频与交付。此处没有人工阶段审批。

## 5. C 阶段：至多一次正式 240k

- 若训练，使用独立 B3 输入和完整 B2 调度。按最终训练位姿重建主训练传感种子和合格 SfM 补充、RENDER/可见性/置信度缓存；位姿未变的只读材料可按哈希复用。保持 Metric3D v2 法线与原生 Z。旧模型权重只用于 A 和静态诊断。新优化从头开始，记录初始化来源、数量、外参加载和实际配置差异。
- 继承 seed 42、每 epoch 重新 shuffle、全分辨率、原深度/法线主系数、B2 的 warmup/refine/reset/恢复、120k 后停止增长且不再删点或 reset。预算累计 240,000，最终零基 step 239999。每 10k 存恢复点，每 30k 跑完整 184 val；保留八个节点。只核对第一正式 batch 与首个实际细化回调。恢复按 `240000-(saved_step+1)`，恢复优化器、完整调度、采样器、RNG 及新增细分状态；评价隔离 RNG。[B2 训练参数及历次恢复定义](14_capture_quality_plan.md)
- 选 checkpoint 使用原 B2 210k **精确** val 值。PSNR ≥24.644204284833826、SSIM ≥0.8045141142995461、LPIPS ≤0.1990245273741691 的有效节点中取全参考合并 Z MAE 最低者，同值取较高 PSNR，再取较早节点。都未满足时，用 240k 列作诊断并标出门槛失败。始终报告 240k。如选出模型的深度 MAE 亦 ≤0.12038714948413506 m，才推荐替换 B2 渲染模型；否则 B2 仍用于推荐渲染，B3 的网格仍可凭其实测值参加网格选择。
- 对 B3 主节点各导出历史支持 Poisson、历史模型 TSDF 和 A 中冻结的新模型网格。新旧模型各按自己正确的相机/缓存处理。不为八个渲染节点各建大网格。若训练位姿变化，再在新位姿上输出独立原生融合参照；位姿未变则引用 A 的同一传感器产物。

## 6. 验收、回传与恢复

**网格只用 val 选择。** 参选对象为 B2、若存在则 B3 主模型的旧支持 Poisson、旧模型 TSDF、新模型网格；原生传感器网格只作参照。以 B2 支持 Poisson 为保底。候选全参考命中 ≥90%、10 cm 正确覆盖不低于 B2、前方冲突不高于 B2，才有资格替换。比较未舍入值；满足三项工程目标者优先，再依次选 10 cm 正确覆盖较高、前方冲突较低、命中 MAE 较低，完全相同保留已有结果，同为新候选按预登记名排序。可明确得出“最佳 RGB 为 B2，最佳网格来自 B3”。工程目标是 **10 cm 正确覆盖 ≥70%、命中 ≥90%、前方冲突 ≤15%**，逐项给出是否达到。B2 的三项为 61.61%、96.43%、22.50%。

**冻结后再读开发 test。** 冻结训练开关、主及末节点、导出阈值和网格选择清单后，在全部 184 test 上一次性评价各 distinct 新产物。旧哈希一致的结果复用。报告 RGB 帧等权 PSNR/SSIM/LPIPS；模型深度全参考合并与逐帧 MAE、P95、偏差、无效数；网格 5/10/20 cm 正确覆盖、命中/缺失、前方冲突和共同命中 MAE/P95。每距离档、每 30 s、同源和未改位姿子集、最差固定相机、改善/退化帧数均给分母。评价脚本沿用原射线第一交点及冲突容差；预测无效不能通过删分母得到合格模型。桌沿、柱面、椅腿、泡沫块按同相机同裁剪、同尺度输出实拍/模型/网格。报告整体与困难位置各自的收益。

**视频与文件。** 新训练交付 1,846 个时间位置的实拍/B2/B3 遮挡对照视频、原始时间戳和遮挡清单；仅有 A 时，RGB 视频直接引用 B2 的 SHA，另交付从同一全程相机轨迹观察旧/新网格的对照视频。若有 C，也交付旧/新网格固定局部图及可定位视角。清单列实际路径、字节、SHA-256、相机/模型/配置/代码身份；回传本项目既有结果父目录下的新 run，重用已核验的旧大文件，只回传新增交付件。保存每阶段状态、日志、PID、退出码、线程、峰值 RAM/显存、耗时、失败实值及重试入口。主训练节点、最终节点、配置、关键网格、视频和评价足以复核。

**资源。** 已有 AutoDL 项目环境和代码继续隔离。先实查 CPU affinity/cgroup、RAM 可用量、磁盘、GPU 与本项目作业状态，再按实际分配使用整卡/CPU。B2 历史训练阶段约 3.6 小时，仅作排程参考。训练、大网格和全量评价顺序运行，流式处理深度、体素块和射线；按实际内存选择数值等价的分块。无独立短训练、参数扫描、截止时间、自动关机或其他项目清理。恢复时查 run 身份和哈希再复用。只向用户仓库推送代码、小配置与报告；AutoDL GitHub 操作先在项目子 shell 启用官方学术加速。大件走已有私有通道，公开材料沿用遮挡。最终给出远端提交、服务器产物、本地收据、真实指标和下一步只针对尚存的失败。
