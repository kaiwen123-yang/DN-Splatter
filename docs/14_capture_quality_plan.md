# capture-full B2：一次完整的质量改进实验

日期：2026-11-21（北京时间）。证据基线：`3728dae350a240d317702d57e560554d529679c6`。状态：**方案已制定，尚未在 AutoDL 执行**。机器协议见 [capture_quality_protocol.json](../configs/capture_quality_protocol.json)，当前复核见 [overview.md](../reports/capture-quality-review/2026-11-21/overview.md)。

## 1. 本轮要解决什么

用户要求明显提高重建质量，并明确不接受无止境的小规模试验。B0 / Metric3D B1 两轮已经完成，B1 模型有所改善，但最终支持网格几乎没有整体改善。现在把直接发现的问题组织为**一次完整场景适配**：局部相机纠正、训练初始化补足、保留与增长足够的高斯、完整训练、同分母评价和多种表面输出。

这是一组有证据支持的联合改动，称为 B2，**不是单因素消融，也不是论文原样 30k**。不会把整套收益分别归给每一个组件。原 VR / s01 / B0 / B1 结果及其原协议均保留。

本轮只有**一个新增正式 DN 训练**，目标累计 **240,000 次更新**。准备阶段的静态核对、现成 checkpoint 的完整 val 评估以及各个正式 30k 节点的全量评价都是主任务的一部分；没有另开的 smoke 训练、参数扫描或阶段人工审批。

## 2. 顺序和复用

1. 复用已授权的 AutoDL 连接、本项目独立环境和 Blackwell 补丁，核对当前项目进程、磁盘/RAM/GPU容量、源文件身份及未提交修改。只对本项目操作，不再重做驱动、Conda、VR Room 或原 bag 审计。
2. 在原 B1 的相机/数据版本上，一次评价已有 step 5000 / 10000 / 15000 / 20000 / 25000 / 29999 的全部 **184 val**。保留旧实际 step，不把旧 step 5000 写成恰好5000次更新。若部分中间 checkpoint 已被移走，按既有清单定位；实际不可用的项标缺失，继续主实验，不训练一个替代品。
3. 在新输入副本中处理明确的局部位姿异常，固定新几何；从主训练观测重建初始化并加入可靠训练 SfM 种子。同一次准备生成原生深度覆盖分解和训练传感器 TSDF。
4. 新初始化从头训练 B2 240k，每累计30k做一次完整 val，保存实际调度、采样和增删点事件。不能从已删到171k的 B1末模型续训冒充B2。
5. 按下述固定 val 规则选 checkpoint，完成全部 test、全程视频、同源与分距离/分时间比较、模型 TSDF 和支持 Poisson，推送小报告及代码，回传用户已授权的本地结果目录。

所有阶段顺序使用整卡和全部已分配 CPU。旧训练峰 RSS 约79GiB，避免把两份图像缓存同时放主存。不要用显存空闲推断主存也够；缓存、块大小和线程预算可作数值等价调整。真正容量不足时保留可恢复状态并如实报告，不静默降低分辨率、删训练帧或截短总步数。

## 3. 几何修复限定范围

### 3.1 已有强证据

full `01293→01294` 在0.195s估计旋转174.87°、平移1.985m；`01306→01307` 在0.200s旋转174.24°、平移1.696m。公开视频参考RGB在两处连续地围绕同一砖柱右转，不支持这一反向跳变。中间13帧含11train、1val、1test。报告和证据图见几何专项。

先检查 `01288–01312` 的源帧关联，再使用区间外可靠主训练地图点重定位 `01294–01306`；同时检查 `01510–01518` 中原先桥接的01514。01514参考帧有明显运动模糊，其29cm局部轨迹偏差证据较弱，不能机械套用与175°跳变相同结论。

### 3.2 求解规则

- 固定区间外可靠训练地图、全局米制和内参。剔除仅由可疑区间支持的3D对应，再用外部训练观测支持的点进行PnP。必要时重新匹配区间外视角、重新三角化局部训练点，并用真实相邻RGB-D约束做有边界的局部优化。
- 局部 BA 如确实需要，只优化训练相机和相应训练点；外部锚点固定。避免把错误分支作为唯一初始化；比较真实特征与RGB-D几何残差，不依赖“注册率100%”自动通过。
- 01298 / 01299等留出仅在修正后的固定训练地图上定位，不能参与地图BA、尺度、初始化或网格融合。原100张辅助图只能维持其既有建图身份。
- 不手写180°翻转，不用线性插值制造位姿，不删除困难帧或改变1478/184/184划分。局部修复有未解决项时，保留真实估计和失败标记，说明其影响并继续整轮；不得无期限卡在同一局部。
- 记录新旧每帧SE(3)变化、匹配/内点、重投影、邻接RGB-D残差及前后图。只改变有数据支持的局部，不重跑全局SfM来替代定位具体问题。

改变训练位姿后，从源主训练数据重建完整初始化。旧点云经过跨帧体素平均，不能仅平移一小撮点就假定污染已移除。

## 4. 观测、先验和初始化

**继续1280×720 RGB、0.3–6m真实传感器Z、B1已完成的Metric3Dv2 ViT-Large法线及现行法线坐标链。** 相机坐标系内的单目先验不因世界位姿局部变化而必须重推理。沿用已核验权重SHA `15328ffc42b528b95f188687418f6f03b3f123eb34ccdbd686c112abbea6d972`。不把单目深度替换/补成传感器真值。

当前深度是在RGB大网格前投影的稀疏观测。训练loss在有效项内mean，并没有因17%覆盖整体关闭。主实验保留该训练loss与原系数；不在此轮同时引入未经实现核验的稠密补洞、法线置信度网络或新深度loss。

正式准备一次统计每帧：原生有效深度、0.3–6m内、畸变处理、投影视场内、竞争遮挡/碰撞、最终RGB深度支持数量；同时记录初始化投影支持。不要把其余83%像素全叫远景。法线参考诊断若需要，使用原生深度网格有足够真实邻域的区域；0个样本必须继续标null，不能填一个角度分数。

初始化规则：

1. 用新训练位姿重建传感器种子，保留现有640网格、步长4、3cm融合和已有边缘/遮挡筛选，记录实际点数，不强制凑成2,001,906。该策略对细杆支持仍可能不足，最终传感器TSDF与局部图将说明其影响。
2. 从修复后最终训练地图导出的SfM点补充目前传感器初始化没有覆盖的表面，包含可靠远景。所有重投影、正深度、夹角与传感支持须按最终训练位姿重新计算，不能沿用旧缓存的质量标记；受局部BA影响的点必须重新导出。每点至少3个主训练观测，中位重投影≤1px、观测重投影P95≤2px、至少一对观测射线夹角≥1°，观测均正深度且坐标有限。辅助图不计入3个主训练支持。原始SfM单位坐标只乘既有全局米制尺度一次；已经米制的坐标直接使用，禁止二次乘尺度。来源、原单位和是否已应用尺度写入清单。
3. 有传感器参考的训练观测，使用`tau=max(0.05m,0.03*Z_sensor)`分类：`abs(Z_point-Z_sensor)<=tau`为一致支持，`Z_point<Z_sensor-tau`为自由空间冲突，`Z_point>Z_sensor+tau`为被前景遮挡，不计支持也不计冲突；没有参考的观测忽略。要求一致支持数≥自由空间冲突数且不接受仅由可疑未修复区间支持的点。无传感器参考的远景点按真实多视角三角化证据筛选，不伪造传感支持。
4. 与传感器点3cm体素去重，优先保留传感器种子；新SfM点保留来源/轨迹标识和颜色。过滤掉的各类数量与全部保留点写清单，阈值不根据test调整；如果没有合格补充点，记录为0并继续，不放宽阈值凑点数。
5. 对**新增SfM种子**的初始化切向尺度，一次性使用`min(历史三近邻平均距离, 0.25m)`；原传感器种子保持历史初始化。此cap等于`0.5*cull_scale_thresh`，避免稀疏邻距一开始形成巨大面片；不是已证实最优值。保持历史方向和扁平比例，颜色/法线只能来自其训练观测。训练期间不持续clamp，不豁免远景world-scale cull。记录cap比例、尺度分位数和投影footprint。

实现中的关键不是只改配置数字：

- 实际细化资格应为`step > 4000 and step < 120000 and step % 24000 > 3*1478 + 800`，在800步回调上检查。首次候选5600；opacity重置24800/48800/72800/96800，各自恢复细化29600/53600/77600/101600。120k前总共115个候选。这是累计零基step规则，实际更新计数另记。
- 继承world-scale检查的`step > refine_every*reset_alpha_every`门，因此新world-scale首次实际检查是29600，**不是5600**。日志补丁不能把这个门删掉。
- densify梯度已按`xys_grad_norm/vis_counts * 0.5*max(H,W)`归一；窗口扩大800时**不把阈值乘8**。保留原分母初始化和更新语义；每次回调统计清空位置核对一次。
- 120000及之后不split、不duplicate、不post-cull、不再opacity reset；后半程只优化已有参数。保存每个细化事件的before/new/union/after恒等式，以及opacity/world/screen/parent-replacement各mask与交集。
- 每epoch新随机排列；断点保存当前排列、剩余索引、epoch、Python/NumPy/Torch及sampler RNG、optimizer与scheduler。完整val运行必须隔离/还原训练RNG与采样状态，不能因评价改变下一轮训练序列。
- 在第一正式batch及第一实际细化事件核对有效配置与梯度，然后持续跑。不要再单开2k/5k smoke训练。

240k使平均每图约162.4次曝光，接近s01的155.4次；这是预算设计依据，不是质量保证。不要机械按点数多少选模型。保存每10k恢复checkpoint、全部30k节点及最终checkpoint；记录实际磁盘成本，无授权不清理旧实验。恢复按`remaining=240000-(saved_step+1)`，不重新加240k、不重置240k原调度。

## 7. 三种完整几何产物

所有融合/支持筛选仅用1478主训练帧，辅助和留出不参与。固定`voxel_length=0.01m, sdf_trunc=0.04m`，不扫参数。两种TSDF输入先明确mask为有限Z∈[0.3,6]m、其余置0，再用float32米和`depth_scale=1.0`。创建Open3D RGBD时显式`depth_trunc=6.000001`（或直接赋已过滤深度），保留恰好6m的有效值，不能遗留默认3m截断。

1. **传感器TSDF：** 用原生深度相机848×480网格及自己的去畸变K，0.3–6m有限Z；`T_world_depth = (c2w_RGB_GL @ diag(1,-1,-1,1)) @ T_RGB_depth`，其中`T_RGB_depth`明确是原生depth→RGB的标定变换、原始标定字段`translation_mm`只乘0.001一次转米（已米制缓存不重复转换），积分外参取逆。原生Z和RGB-Z各自沿对应相机光轴定义，范围裁剪的相机系差别写清楚。先NoColor即可，不能把当前RGB前向投影稀疏孔洞当稠密原生深度。float米`depth_scale=1`，保留无效。原生K不可机械套用RGB的半像素修正。
2. **模型TSDF：** 主checkpoint全部训练视角RGB网格上的有限预测Z，alpha≥0.5，预测Z在0.3–6m。融合值就是预测Z，不以传感器数值替代；不增加传感一致性硬筛。RGB K按既有Nerfstudio→CV中心约定减一次0.5。流式ScalableTSDF，复用已装Open3D，不构造巨大密集体素数组。
3. **支持Poisson：** 沿用docs/13与B1实际代码/阈值，depth11、1cm融合、训练传感支持及面冲突裁剪，全部参数语义diff公开。使用新主checkpoint和新相机，不能误读B1旧深度缓存。

模型TSDF与支持Poisson包含不同支持mask，是**完整导出流程对照**，不能称为仅更换成面算子。原始Poisson已有B0/B1错误样本，不为重现已知伪面再开本轮主产物。

三种表面均在全部val和test参考像素上报告命中/缺失、5/10/20cm正确覆盖、`max(.05,.03Z)`前方冲突、命中MAE、共同命中MAE、P50/P95、距离/时间分组。原生sensor TSDF是输入几何参照，**不是GT或效果上限**。

实用模型导出选择：val命中≥90%的候选优先，在候选中按全参考≤10cm正确覆盖最高选择，精确并列取前方冲突较低，再取命中MAE较低。若两者均不足90%，标注覆盖条件失败并按同顺序选择；保留两份完整结果，不隐藏落选输出。sensor TSDF独立列出，不当作DN产物替换。

## 8. 完成标准与实际质量目标

完成是累计240k、完整val/test、1846时间位置对照视频、三种几何产物及清单均落地。质量不佳也完成并报告，不把“跑通”写成“质量已达标”。

下一轮的**工程目标而非保证或停止门槛**：相对B1，val PSNR至少提高2dB；深度MAE至少降低25%；模型导出≤10cm正确覆盖从58.76%提高到至少70%，命中≥90%、前方冲突≤15%。同时要求原s01同源视角恢复、背景不再大块丢失，桌沿/椅腿固定相机预览可辨且无新增大片伪面。目标没有达成就诚实记录，不改评价分母使其达标。

若训练明显改善但网格不改善，以传感TSDF/模型TSDF/Poisson差异决定后续表面方法；若传感TSDF也明显重影，下一项才应侧重更广范围的RGB-D轨迹优化。若输入几何较好、B2完整训练仍不能维持表面和细结构，再安排独立的AGS-Mesh或真实2DGS+传感监督完整对照。它们是后续候选，不在本轮并行铺开安装和训练。
