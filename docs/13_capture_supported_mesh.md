# B0 / B1 统一的传感器支持网格导出协议

日期：2026-11-20，北京时间。**本文件是预先固定的工程适配方案，尚未执行，不代表已证实最优。** B0为已有Omnidata全程30k；B1为下一轮仅替换Metric3Dv2法线的完整30k。两者使用同一冻结几何、主train划分和以下全部导出规则，val/test只用于评价。

B0原始500万点、Poisson depth9结果继续保留；B1也交付相同原始协议的点云和网格。各自再生成本文件的派生结果，用于区分模型变化和导出变化。本方案仅承诺处理全程主训练视角中有近距传感支持的表面，不承诺恢复整个大厅的远景。

## 1. 采样候选和确定性

使用各自最终step29999 checkpoint，按冻结顺序遍历全部1478张主train，辅助建图图像不参与。像素候选同时满足：

- 预测Z、alpha、法线有限，法线非零；alpha≥0.5。
- 预测Z和同像素传感器Z均在闭区间[0.3,6]米。
- `abs(predZ-refZ) <= tau(refZ)`，其中 `tau(d)=max(0.05m,0.03*d)`。

保持原像素、尺度和OpenGL/CV转换；反投影仍用**预测Z**，法线仍来自对应模型，不用传感器Z替换预测几何，不增加法线夹角阈值。

每视角最多25907点，候选不足就全部保留，不重复抽样补数。基准种子42；B0/B1按相同帧序为每帧的全部H×W像素生成固定随机优先级，再从候选中取优先级最小的目标数量。每帧即使候选为空也消费固定数量随机数，避免候选变化使后续帧随机序列错位。记录RNG实现/版本，保存源帧ID、源像素索引和各条件剔除数。

最多约38290546点只是采样上限。逐视角或分块写出，再实际执行0.01m体素融合：体素键采用最终米制世界坐标 `floor(xyz/0.01)`，固定世界原点；各体素对XYZ/RGB/单位法线等权累加，合并后法线重新归一化。记录融合前后点数；只有零或非有限融合向量按数值无效排除，不增加角度筛选。历史导出器的`down_sample_voxel`字段没有实际执行该操作，不能仅设参数。

## 2. Poisson及原始派生面

对融合点云执行一次Open3D Poisson：depth=11、scale=1.1，线程使用实际项目CPU预算。沿用最低1%密度顶点删除，保留此时的未做传感支持裁剪网格。记录实际点云范围及名义最细格 `1.1*max_axis_extent/2**11`；这不是几何误差保证。不要加平滑、补洞、重新着色或额外参数试跑。

## 3. 固定的表面支持／自由空间裁剪

**唯一裁剪查询点采用每个三角面的几何中心，不用顶点投票替换它，也不细分后再改变规则。** 每个中心对全部主train相机各查询一次，辅助图和留出图不查询。训练深度仍为原固定0.3–6m传感器Z。

对世界点转换为OpenCV相机点 `(x,y,z)`，要求坐标有限且z>0。使用已冻结Nerfstudio像素边界坐标内参：

```text
u = fx*x/z + cx_ns
v = fy*y/z + cy_ns
```

只有`0 <= u < W`且`0 <= v < H`才在图内；查询像素`i=floor(u), j=floor(v)`。这里对应像素中心i+0.5，不再额外增加半像素。取原深度`d=refZ[j,i]`最近邻值，不插值、不填孔。d非有限或不在[0.3,6]时不投票。

| 对合法查询的判定 | 计数 | 含义 |
| --- | --- | --- |
| `abs(z-d) <= tau(d)` | S加1 | 观测表面支持 |
| `z < d-tau(d)` | C加1 | 面在已观测表面前方，构成自由空间冲突 |
| `z > d+tau(d)` | 不计票 | 面可能被前景遮挡，不能据此判错 |

图外、相机后方、无深度参考同样不计票。每个不同主训练源帧最多一票；两帧不等于统计独立测量。

**固定保留条件为 `S >= 2 and S > C`。** 即至少两张训练图支持，且支持票严格多于前方冲突票。`S<2`归为支持不足；`S>=2且C>=S`归为冲突占优；两类删除计数分别报告。采用多数规则，是为了避免一两次深度/位姿噪声否决已有大量支持的表面；其最优性尚未验证。

删除不满足条件的面，清除失去面引用的顶点，其余拓扑保持。保留未裁与裁后两个产物，不再平滑或补洞。裁空、覆盖大幅下降也如实报告，不查看test后放宽阈值或循环重跑。无法观测的远景因此缺失，应作为本方法范围与覆盖损失记录。

## 4. 流式实施和资源

不构造“全部面×全部相机”的投票矩阵。保留面中心及S/C计数，按相机读取一张训练深度、分块投影面中心并累加；单相机参考用完释放。点云融合分块累加，不同时常驻全部38M采样点、多份float64副本、全图训练缓存和训练模型。

本轮完整高内存Poisson阶段与正式训练顺序执行。按实际RAM/GPU容量调整分块和缓存，实现数值等价；不降采集范围、不改本协议阈值、不强杀其他任务、不设置完成deadline。记录各阶段RSS、GPU和cgroup值，区分本进程与设备/容器总量。

## 5. 评价必须同时覆盖精度和缺失

全部184 val及184 test按固定相机与传感器参考评价，参考分母为原0.3–6m有效像素，不能随mesh命中或预测误差变化。报告原始B0/B1 depth9，以及B0/B1本协议派生网格；每个结果分别给出：

1. 完整参考像素数、有限正Z命中数、无命中数和覆盖率。
2. 命中处MAE/RMSE/P50/P95，明确这是条件指标；无参考或无命中时为null。
3. **有效准确覆盖率**：`count(hit且abs(meshZ-refZ)<=tau(refZ))/全部参考像素数`。同时报告固定绝对误差≤5/10/20cm的正确覆盖率。无命中不能算准确；不能靠删掉难像素提高这些分数。
4. 首交点低于0.3m比例、`meshZ<refZ-tau`的前方冲突比例与有符号残差。分母固定为全部参考像素，同时附命中分母口径。
5. 相同帧上B0/B1及原始/派生网格共同命中的交集指标和交集大小；模型Z、融合PCD、mesh的固定桌沿/柱面/椅腿对照也使用明确共同支持。

各自完整参考口径是主报告，共同交集只用于定位变化，不替代覆盖统计。指标按逐帧等权和参考像素合并分别汇总，保留30秒时间窗及最差视角。缺失严重的结果不能只凭较小命中MAE称为改善；有效准确覆盖和实际画面也须一起判断。

完整产物包括：采样筛选统计与来源、融合点云、Poisson未裁网格、最终裁后网格、S/C分布与两类删面数、全局及固定局部预览、全部留出评价和路径/字节数/SHA清单。所有质量统计是同采集传感器一致性，不冒称独立几何真值。
